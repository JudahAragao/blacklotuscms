# Environments

## Development
- **Database:** PostgreSQL via Docker (container: blacklotus-postgres)
- **Storage:** Local (./uploads)
- **Secrets:** .env (auto-generated by setup_dev.sh)
- **Setup:** `bash setup_dev.sh` (idempotent)
- **Command:** `bun run dev`

## Production (Docker + Blue/Green)
- **Database:** PostgreSQL container (postgres:15-alpine, shared)
- **Storage:** Local (container volume) or S3/R2
- **Secrets:** .env per environment (blue/green)
- **Command:** `docker compose up -d` (via GitHub Actions deploy.yml)

## Required Environment Variables
```bash
DATABASE_URL=postgresql://postgres:PASSWORD@localhost:5432/blacklotuscms
NEXTAUTH_SECRET=hex_string (auto-generated by setup_dev.sh)
NEXTAUTH_URL=http://localhost:3000
DOMAIN=localhost
CSP_NONCE_ENABLED=false
STORAGE_DRIVER=local
UPLOAD_DIR=./uploads
SANDBOX_MEMORY_LIMIT=512
SANDBOX_TIMEOUT=30
ADMIN_EMAIL=admin@blacklotuscms.com
ADMIN_PASSWORD=CHANGE_ME
```

## Security Headers (next.config.ts)
- X-DNS-Prefetch-Control: on
- Strict-Transport-Security: max-age=63072000; includeSubDomains; preload
- X-Frame-Options: SAMEORIGIN
- X-Content-Type-Options: nosniff
- Referrer-Policy: origin-when-cross-origin
